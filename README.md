# Cronograma-e-Or-amento-de-Viagem-Curitiba-Recife
Projeto prático que organiza e calcula automaticamente o orçamento de uma viagem de Curitiba para Recife. Criado para estudantes iniciantes no GitHub, ele substitui planilhas por uma página web dinâmica que soma gastos com passagens, hospedagem e alimentação, funcionando em computadores e celulares.
